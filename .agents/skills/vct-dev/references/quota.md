# Quota Panels (`src/core/src/quota/`)

## Shared runtime, cache, and auth invariants

- Every gauge reports percent **consumed** (never remaining).
- Panels are app-only, shown only when credentials exist, laid out uniformly by `quota_grid` / `grid_cells` (`MAX_QUOTA_PANELS` is only a capacity/test hint). Adding a provider panel also requires bumping `CONFIG_VERSION` and adding a `(version, panel)` row to `PANELS_ADDED_BY_VERSION` in `src/core/src/config/mod.rs` (see `references/config-update-runtime.md`).
- One shared poll cadence from `config.usage.quota.refresh_interval` (default 60 s); only Antigravity raises its floor to `ANTIGRAVITY_MIN_REFRESH_SECS` (300 s).
- `QuotaOutcome::Transient` (network error, `429`) retains the last-known-good snapshot indefinitely with a growing staleness marker (no stale-drop). Because retention is unbounded, `~/.vct/quota/<provider>.json` uses a versioned envelope (`{"schema_version", "provider", "snapshot"}`): bump `CachedQuota::SCHEMA_VERSION` whenever snapshot derivation changes so old semantics are dropped on load. Keep one file per provider (blind atomic overwrite with one writer per file; do not merge into one multi-provider file).
- CLI version probing (`detect_cli_version`, cached daily in `~/.vct/version/<provider>.json`) is opt-in via `quota::enable_cli_version_detection()` in `main.rs` so library callers and tests never spawn subprocesses or touch `~/.vct`.
- Core `quota` exposes public raw fetchers for `vct quota <provider>` (`main.rs::run_quota`) and MUST NOT import `display`.
- Token refresh (Claude, Codex, Grok in `refresh.rs`): `update_json_file_in_place` mutates a whole `serde_json::Value` to preserve unknown fields and writes back in that CLI's exact timestamp format (Claude `expiresAt` ms, Grok `expires_at` RFC3339, Codex `last_refresh` RFC3339 — for Grok, updating only the selected entry's `key` / `refresh_token` / `expires_at` so sibling login entries stay intact). It re-checks file mtime immediately before writing to abort if the official CLI rotated first, and treats an unpersisted rotation as a refresh **failure** (never cache an unpersisted rotated token). Refresh failures arm a 5-minute `RefreshCooldown` keyed on credential file mtime (re-login resets immediately). Persistent failure sets `needs_login` independently of `QuotaSource` (so Codex still displays session-fallback data beside the hint).

## Provider-specific quirks and dead ends

- **Claude**: No `statusline` subcommand (removed). Calls `GET https://api.anthropic.com/api/oauth/usage` with `anthropic-beta: oauth-2025-04-20`. Deliberately omits `x-stainless-*` headers (frozen SDK headers fingerprint worse than none). Volatile per-model `weekly_scoped` limits MUST use lenient parsing (`de_lenient_limits`) and silently drop absent/malformed scopes. On macOS, Claude stores credentials in Keychain, so the Claude panel is absent there. Login hint: `run: claude auth login`.
- **Codex**: `GET /wham/usage` + best-effort `GET /wham/rate-limit-reset-credits` (details-only `401` triggers one refresh+retry; any details failure preserves usage summary). `available_count` stays authoritative even when the capped `credits` list is shorter. Reactive-only refresh (`auth.json` has no expiry). The local session-log fallback (`quota/codex_session.rs`) scans both active (`sessions/`) and archived (`archived_sessions/`) roots with separate bounds: bulk archiving can overwrite old files' mtimes with today's timestamp, so `archived_sessions/` MUST be prefiltered descending by `rollout-<ISO-8601>` filename before ranking by mtime. Login hint: `run: codex auth login`.
- **Copilot**: `~/.copilot/config.json` is JSONC — strip comments string-aware so `"https://github.com:login"` keys survive. `serde_json` lacks `preserve_order`, so fallback account selection uses an explicit order (`github.com` first, then lexicographical; skip non-URL keys). GHE hosts hit `api.<host>`. Maps `premium_interactions` only (`100 - percent_remaining`). No refresh (`gho_` is long-lived). Login hint: `run: copilot login`.
- **Cursor**: Reads WorkOS JWT from `~/.config/cursor/auth.json` (`$XDG_CONFIG_HOME` aware; Linux-oriented), read-only (never writes back). `totalPercentUsed` / `autoPercentUsed` / `apiPercentUsed` are literal percent **used** — NEVER invert them. Login hint: `run: cursor-agent login`.
- **Grok**: In `~/.grok/auth.json`, the access token is the `key` field (not `access_token`), selected deterministically (refreshable OIDC > API key > latest `expires_at` > entry key). `X-XAI-Token-Auth: xai-grok-cli` is mandatory. Response is proto3 JSON — zero-valued scalars are omitted (absent `creditUsagePercent` means 0%, never an error; money is `{"val": <cents>}` or `{}`). Plan line from `GET /v1/settings` is cached against `auth.json` mtime and cleared *before* fetching so failures leave it blank rather than stale. Token refresh uses OIDC discovery (`<issuer>/.well-known/openid-configuration`), never a hardcoded token URL, with no client secret. Login hint: `run: grok login`.
- **Antigravity**: Runs `agy --log-file <null device> -p /usage --output-format json` (one run is ~3 s and ~260 MB, hence the 5-minute floor). `locate_agy` checks `PATH`, then `~/.local/bin/agy` and platform build paths (needed because `agy` can be a shell alias invisible to child processes), preferring a build with its own sign-in or `agy` with a stored sign-in so a signed-out `agy` never hides a working build. Builds with their own sign-in need no OAuth sign-in store: finding the binary is their presence test, they skip `NeedsLogin` / `signed_out_mtime` holds, and failed sign-in simply retries next tick. Never read or write `agy`'s OAuth token — presence and `signed_out_mtime` check OS credential metadata (`CredReadW` `LastWritten` on Windows, attributes-only `SecItemCopyMatching` on macOS so Keychain never decrypts/prompts) or fallback file mtime. Always pass `--log-file <null>` to avoid writing log files per poll. Keep TUI and CLI subprocess I/O distinct: in the TUI, close stdin and capture stderr (logging a stderr tail only when no usable JSON arrives) so a sign-in prompt cannot steal keystrokes or draw over the screen; in `vct quota antigravity`, let stderr inherit so a sign-in prompt explains its wait. Ignore exit status (failed runs still emit JSON). Signed-out or expired-offline `agy` blocks ~60 s and may launch a browser: short-circuit absent sign-in to `NeedsLogin`, record pre-run `signed_out_mtime` in the cache via `QuotaOutcome::Data` (not `NeedsLogin`) so restarts keep the hold until re-login, and skip running when `oauth2.googleapis.com:443` TCP probe fails (skip probe when `HTTPS_PROXY`/`ALL_PROXY` is set). Login hint: `run: agy acp --login`.
    - **Dead ends (do not re-attempt — issue #349)**: Direct HTTP (`retrieveUserQuotaSummary`) was tried and removed because refresh requires an IDE client secret that must not be committed or extracted, and non-CLI UAs lose the Gemini pool. `agy acp` has no quota method; local Connect RPC needs a child-only CSRF token. **Never run `agy remote-control serve --help`** (starts a second daemon). Raw endpoint shapes live in `docs/quota.md`.
- **No Gemini panel**: intentionally omitted.
